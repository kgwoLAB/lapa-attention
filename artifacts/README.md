# Artifacts

The following historical bundles are **local-only and Git-ignored**. They are
not included in a GitHub clone. They remain on the original workstation so the
old asset hashes and migration evidence can still be checked without mutation.

- `checkpoints/legacy_native_v4/`: six unchanged representative raw state dicts
  and original metric files (first seed 2026090720; not best-seed selection).
- `reference/native_v4/`: original configuration and ten-seed summary, preserved
  as historical context rather than regenerated by the package.
- `verification/`: package smoke tests and finite-sample migration comparisons.

Use `scripts/convert_checkpoint.py` to create versioned standalone checkpoints.
Converted weights have the same tensors and embed a full program-bank hash.
No SDPA-trained checkpoint is fabricated. New smoke/train outputs are kept in
the separate git-ignored `outputs/` directory.

Checkpoint distribution has not been publicly licensed by this extraction;
checkpoints are local and git-ignored pending review. Verification results are
not replacements for published or confirmatory research metrics.

Curated, path-sanitized research snapshots and aggregate figures are under
[`research_archive/`](../research_archive/README.md), with separate export
hashes and explicit reproduction limitations. Project-owned code/docs use
Apache-2.0; this does not license excluded datasets or weights.
