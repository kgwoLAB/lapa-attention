# Local-only datasets — not included in GitHub clones

The original workstation has the experimental data in this directory, unchanged.
These local copies and `manifests/assets.json` are not GitHub upload candidates.
A fresh clone does not contain them. The descriptions below document local
assets, not a data download or a grant of redistribution rights.

| Bundle | Included files | Role |
|---|---|---|
| native_v4 | train/development/evaluation JSONL and original config | DNS, Modbus, TLS, SMB2 raw bytes + scoped field labels |
| address_v1 | development/terminal tensors, full manifests and hash sidecars | Earlier DNS/x86 address relationships, saved counterfactual and scaling panels |

Native message counts are 3089 / 522 / 74. Field counts are 12900 / 3200 / 347.
The train/evaluation identities and capture/group metadata are unchanged.
This is a small, already inspected development corpus, not a newly blinded or
universally representative benchmark. No original full PCAP files are copied.

The address archive includes program windows originating from system binaries
and traffic extracts. Some terminal panels are existing counterfactual edits;
the panel names/manifests preserve that distinction. They are not new synthetic
protocols created for this package.

## Distribution is not yet cleared

Raw payload bytes may retain hostnames or other sensitive values, and the local
source chain does not establish a blanket redistribution license. Copies are
made at the user's request for local collaboration; this preparation does not upload them.
Native/address directories are ignored by git until the rights holder clears
the source licenses and privacy scope. Do not blindly force-add them.

After clearance, provide the same reviewed bundle through the chosen approved
collaboration channel and retain these hashes. Sanitizing payloads would create
a new dataset version and must not silently replace the original experiments.
